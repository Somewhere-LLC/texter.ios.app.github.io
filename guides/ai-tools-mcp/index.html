ChatGPTやClaudeから、Texterの文字起こしを読む方法

会議や講義の文字起こしを、コピーして貼り付けずに、ChatGPTやClaudeに読ませて質問できます。この機能がTexter MCPです。読ませるノートは、自分で選びます。接続の手順と、実際に返った答えを紹介します。

できること

Texterの文字起こしを、ChatGPTやClaudeに読ませて質問できます。AIツールは、読めるようにしたノートを検索し、本文を引用して答えます。ノートをコピーして貼り付ける手間は要りません。

上の画面は、動画の文字起こし1件を読めるようにして、ChatGPTに頼んだときのものです。同じ状態で、次の3つを頼みました。

頼んだこと
最近のノートのうち、いちばん新しいものの要点を3行で（ChatGPT）
答え
3行の要点と、Texterでノートを開くリンクが返りました。
頼んだこと
血糖値について話したノートを探して、就寝前の血糖値について何と言っているか（ChatGPT）
答え
該当のノートを見つけ、本文を引用して答えました。
頼んだこと
骨やホルモンについて何と話しているか、本文を確かめて（Claude）
答え
本文の該当する2行を引用しました。文字起こしの誤りの可能性も指摘しました。

Texter MCPは、Premiumに含まれる機能です。プランは料金と利用条件で比べられます。

こんなことに使えます

AIツールは、読めるようにしたノートの題、本文、要約から語で探し、録音した日でも絞り込めます。

会議のあとに整理する

「昨日の定例会議のノートを読んで、決定事項と担当者を表にして」

ノートを1件読ませて、整理を頼む使い方です。上の実例と同じ頼み方です。

複数の打ち合わせをまとめる

「A社との打ち合わせのノートを探して、先方の要望をまとめて」

複数のノートをまたいで探せます。見つかるのは、社名などの語が文字起こしに入っているノートです。見つからないときは、別の語でも試してください。

期間で振り返る

「先月のノートから、繰り返し出てくる課題を挙げて」

録音した日で絞って、まとめて読ませる使い方です。

このページで実際に試したのは、ノート1件の状態です。複数のノートをまたぐ頼み方は、機能の仕様をもとに書きました。答えは、元のノートと見比べて確かめてください。

使う前に

  • Texter MCPは、Premiumに含まれる機能です
  • Texterを最新のバージョンにしてください
  • Texterで、AppleかGoogleのアカウントでサインインし、ノートを同期している必要があります

Texterの「設定 > アカウント > Texter MCP」を開くと、「はじめかた」に3つの手順が並びます。このページの説明も、同じ順番です。

アプリに「Texter MCP」が見当たらないときは、アプリを最新にして、しばらく待ってから開き直してください。

手順1：AIツールに接続する

どのツールでも、接続先のURLは次の1つです。

https://mcp.texter.work/mcp

使うツールの手順へ進んでください。Claude、Claude Code、Codex、ChatGPT、Museの5つを載せています。

Claude（claude.ai）

  1. パソコンのブラウザでclaude.aiを開く
  2. 設定のコネクタで、「カスタムコネクタを追加」を選ぶ
  3. 上のURLを入れて追加する
  4. Texterの許可の画面が開いたら、サインインして許可する

プランや設定によっては、この項目が表示されない場合があります。表示されないときは、Claudeのヘルプを確認してください。

Claude Code

パソコンの端末で、次のコマンドを実行します。

claude mcp add --transport http texter https://mcp.texter.work/mcp

続けて、Claude Codeで /mcp を開き、texter を選んで認証します。ブラウザでTexterの許可の画面が開くので、サインインして許可してください。

Codex

パソコンの端末で、次の2つのコマンドを順に実行します。

codex mcp add texter --url https://mcp.texter.work/mcp
codex mcp login texter

ブラウザでTexterの許可の画面が開くので、サインインして許可してください。

ChatGPT

  1. 「プラグイン」の画面を開き、右上の「追加」から「カスタム MCP サーバーを追加」を選ぶ
  2. 名前に「Texter」などを入れる
  3. 接続タイプは「サーバーURL」を選び、上のURLを入れる
  4. 認証は「OAuth」を選ぶ
  5. リスクの注意を読み、「理解したうえで続けます」に印を付けて作成する
  6. Texterの許可の画面が開いたら、サインインして許可する

プランや管理者の設定によっては、この項目が表示されない場合があります。表示されないときは、ChatGPTのヘルプを確認してください。

Muse

  1. Museのチャットで、Texter MCP（URLは上のもの）にカスタムコネクタで接続したいと頼む
  2. 表示される接続のカードの「連携する」を押す
  3. 注意を読んで「次へ」を押し、クライアントIDにtexter-meta-museを入れて「追加」を押す
  4. Texterの許可の画面が開いたら、サインインして許可する

Museは、ツールを使うたびに「mcp.texter.workとの情報共有を許可しますか」と聞くことがあります。「一度だけ許可」を選ぶと毎回聞かれ、待っている間に時間切れになることがあります。毎回聞かれたくないときは、「このサイトで常に許可」を選んでください。

許可の画面で確かめること

どのツールでも、接続の途中でTexterの「AIツールの接続を許可しますか？」の画面が開きます。

  • Texterアプリと同じアカウント（AppleかGoogle）でサインインします
  • 画面に出る接続元（例：chatgpt.com）が、いま使っているツールか確かめてください
  • 「この接続を自分で始めていなければ、許可しないでください」と出ます。心当たりがあるときだけ許可します

接続できたか確かめる

Texterの「設定 > アカウント > Texter MCP」を開きます。「接続中のAIツール」に、つないだツールが表示されます。

手順2：アプリで読めるノートを選ぶ

接続しただけでは、ノートは読めません。AIツールが読めるのは、Texterで読めるようにしたノートだけです。まず1件選びます。

  1. ノートを読めるようにする

    Texterでノートを開き、メニューから「Texter MCP で読めるようにする」を選びます。「設定 > アカウント > Texter MCP」からも、ノートを選べます。

    確認の画面の内容は、次のとおりです。読んだうえで「同意して読めるようにする」を押してください。

    • このノートのテキストをクラウドに送ります
    • 録音などの元のファイルは送りません
    • すでにツールに渡した内容は、あとから取り消せません

    複数のノートをまとめて選ぶ方法は、次の「読める範囲は自分で決められます」で説明します。

    状態が「接続したツールから読めます」になれば、準備は終わりです。「準備中」の間は、少し待ってください。

手順3：AIツールで試す

AIツールに、次のように頼んでみてください。

  • Texterの最近のノートのうち、いちばん新しいものの要点を3行で教えて
  • Texterで血糖値について話したノートを探して、就寝前について何と言っているか教えて
  • Texterのノート「ノートの題」を読んで、決定事項をまとめて

検索は、語が一致するノートを探します。短い語で頼むと見つかりやすいです。文章で頼んでも、多くのAIツールは語に分けて探します。0件でも、ノートが無いとは限りません。読めるノートに「会議」の語が無い状態で「会議」と検索したときは、0件でした。別の語でも試してください。

見つからないときは、Texter MCPの画面の「AIツールから読んでみましょう」にある例文のIDの行も、一緒にAIツールへ貼ってください。例文の場所は、使う前にの画面の上の段をご覧ください。

読める範囲は自分で決められます

  • 読めるようにするノートは、1件ずつ選ぶのが基本です
  • 「設定 > アカウント > Texter MCP」の「読めるノート」で「選択」を押すと、複数のノートをまとめて、読めるようにしたり読めないようにしたりできます。「すべて選択」で選ばれるのは今あるノートだけで、これから作るノートは含まれません
  • これから作るノートも自動で読めるようにする設定は、任意です。オンにするまでは、自動では読めるようになりません
  • 接続したAIツールは「接続中のAIツール」で確かめられます。不要な接続は「接続を解除」で外せます
  • 読み取り専用です。AIツールから、ノートを書き換えたり削除したりはできません

安全について

  • 読めるのは、アプリで読めるようにしたノートだけです
  • いつでも解除できます。解除すると、そのAIツールは、それ以降ノートを読めません
  • すでにAIツールに渡った内容は、あとから取り消せません。渡った後の扱いは、そのAIツールの規約と設定に従います
  • AIの答えは、元のノートと見比べて確かめてください。文字起こしの誤りがあることもあります
  • 同じアカウントでつないだAIツールすべてが、読めるようにしたノートの対象です。読めるようにするノートは、必要なものだけにしてください

送る内容と保存の扱いは、プライバシーポリシーの「外部のAIツールとの連携」に書いています。

接続を解除する

  1. Texterで「設定 > アカウント > Texter MCP」を開く
  2. 「接続中のAIツール」で、解除したいツールの「接続を解除」を押す
  3. 確認の画面で解除する。解除すると、すべての端末で接続が切れる

AIツールの側にも接続が残るときは、各ツールの設定から外してください。ノートごとに読めないようにするには、ノートのメニューから「Texter MCP で読めないようにする」を選びます。

接続を解除したAIツールは、その時点からノートを読めません。ノートごとに読めないようにした場合は、反映が終わるまでの間だけ読めることがあります。

うまくいかないとき

アプリに項目が無い
アプリを最新にして、しばらく待ってから開き直してください。
「Premiumで使えます」と出る
Texter MCPはPremiumで使えます。購入したときと別のアカウントでサインインしていないかも確かめてください。
接続したのにアプリに出ない
許可の画面で、このiPhoneと同じAppleかGoogleのアカウントでサインインしたか確かめてください。
ノートが見つからない
そのノートを読めるようにしてあるか、状態が「接続したツールから読めます」かを確かめてください。短い語で検索し直すのも有効です。
「準備中」のまま
通信を確かめて、しばらく待ってください。「送れませんでした」と出たときは、もう一度試してください。

よくある質問

録音の音声もAIツールに渡りますか。

読めるようにしたノートのテキストを送ります。録音などの元のファイルは送りません。

AIツールからノートを変えられますか。

読み取り専用なので、書き換えや削除はできません。

Premiumをやめるとどうなりますか。

AIツールからノートを読めなくなります。再開すると、また読めます。

長く使った接続は、そのまま使えますか。

AIツールから、接続し直しを求められることがあります。そのときは、同じ手順で接続し直してください。

iPhoneがオフラインのときは読めますか。

iPhoneがオフラインの間は、最後に同期した内容が読まれます。

パソコンのツールは端末ごとに表示されますか。

パソコンのツールは、端末ごとではなく1件にまとまって表示されます。
